Review

Select products on the Products page, then open them side by side.

Edit in a spreadsheet

Open items in the Review grid and download them with Excel. Change values in Excel, keep the first column (Item Number), then upload the file here. Harim compares every cell with the current value and opens what changed in the Review grid, where you check it and save it to your draft for approval.

Data Import

Everything the viewer uses is loaded here, in any order. Files are read in your browser and never uploaded.

Upload everything

Choose the export folder (or one product file with an <ID> column and any attributes), then select all the reference Excel files at once. Each file is recognised and loaded into the right place; a product file can go in with the reference files too.

Sources

Export folder

PIM export CSVs (Item Identifiers is the master list). Drives Products, Review, Export and all item counts.

Attribute model

Attribute groups, attributes and lists of values in one workbook (PIM Load Attributes). An attribute-groups sheet also works.

Category tree

<ID> | Category | Subcategory | Cat-ID. Linked to items through the classification reference.

Vendor alignment

Vendor #, category manager, buyer and contacts. Linked to items by Supplier ID.

Value translations

French / Spanish wording for list values, e.g. Warranty Policy. Fills "Warranty Policy - French" automatically from the English value.

Marketing Brand Names

Approved brands per Supplier ID, used by Brand cleanup, the item panel and Item Load.

List of values (standalone)

Only needed when not using the attribute model, which already contains the lists of values.

New item files (the New Item Load Sheet or a supplier's own layout) are loaded on the Item Load tab.
